# Erwaa_AI_ITU_Hackthon
This repository contains demo files of the Erwaa AI application, which is an irrigation smart system merge AI with IoT technologies to get a more efficient irrigation solution  
This Repository Contain :
- AI Layer 1 Model: to forecast soil moister and  calculate related Evapotranspiration.
-  AI Layer 2 Model: to predict amount of water required in irrigation
-  Backend Layer 3  Components: contain backend low code settings (Screenshot).(Server)
-  Interterface Dashboard Screenshot.
-  Data Exported from solution.

All Data Used in this application are open access datasets can be found on link below:
- Dataset 1:  https://data.mendeley.com/datasets/cjb4vy4mzj/3 
- Dataset 2: https://zenodo.org/records/14827769
